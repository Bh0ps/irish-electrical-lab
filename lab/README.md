# Irish Electrical Lab application

See [the project usage guide](../README.md) for the Windows launcher, study controls, model assumptions and verification status.

Version **1.2.1** adds automatic single-step progression after correct guided connections and fixes default control-wire identification. Manual conductor choices and incorrect wiring remain available. See [the desktop guide](desktop/README.md) for the focused `--verify-guided-build` native diagnostic.

- `npm run dev`: development preview at `http://127.0.0.1:5173`.
- `npm run build`: produce the local static app in `dist/client`.
- `npm start`: serve the built app at `http://127.0.0.1:4173`.

The delivered app includes all assets locally. The learner can use it without internet access. Public reference links are optional external reading.
